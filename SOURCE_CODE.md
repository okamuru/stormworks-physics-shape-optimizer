# Corresponding Source Code

This package contains Stormworks Physics Shape Optimizer V1.1.0 Alpha.

The complete corresponding application source for this binary release is the
Git tag `v1.1.0-alpha` at:

https://github.com/okamuru/stormworks-physics-shape-optimizer/tree/v1.1.0-alpha

Build instructions are in `BUILDING.md` in that source tree. The GitHub Release
page also provides automatically generated source archives for the same tag.

The release uses unmodified Qt 6.9.3 and Qt for Python 6.9.3. Their corresponding
sources are available from the version-fixed official archives below:

- Qt 6.9.3: https://download.qt.io/archive/qt/6.9/6.9.3/single/qt-everywhere-src-6.9.3.tar.xz
- Qt for Python 6.9.3: https://download.qt.io/official_releases/QtForPython/pyside6/PySide6-6.9.3-src/pyside-setup-everywhere-src-6.9.3.tar.xz

Additional version-fixed source locations and license notices are listed in
`THIRD_PARTY_NOTICES.md`.
